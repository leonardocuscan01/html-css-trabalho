o que é cliente

O cliente é onde o acesso ao site acontece, seja por meio de celular, televisão, computador, notbook e etc.

o que é html

Html é uma linguagem de marcação usada para criar o visual (esqueleto) de uma aplicação web, usando as tags para que o navegador entenda o que cada parte significa.

o que é o css

O css é uma linguagem que estiliza e organiza visualmente os elementos do html para que fiquem visualmente mais bonito e de facil acesso.
